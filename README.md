# Meta Ads MCP – Gestão

Para instalar, envie esta mensagem ao dot ou ao Codex:

> instale esse plugin https://github.com/zaip-ai/zaip-plugin-meta-ads-mcp-gestao

Quando a Meta abrir a tela de autorização, escolha a conta que você usa para gerenciar anúncios.

<details>
<summary>Instruções para o agente instalador</summary>

No Codex local, baixe ou reutilize este repositório. A partir da raiz, registre a pasta como fonte local e instale o plugin `meta-ads-gestao@zaip-meta-ads-plugins` no perfil de usuário atual, para que fique disponível em outros projetos.

Para uso no navegador, verifique se o workspace atual do ChatGPT já tem um plugin conectado a `https://mcp.facebook.com/ads`. Se precisar criá-lo e houver permissão, use **Plugins → Add custom MCP server**, escolha **OAuth** e selecione **Create as a plugin**. A conexão web é configurada separadamente da instalação local.

Deixe a pessoa concluir o OAuth. Confirme o acesso em cada cliente disponível com uma consulta de leitura às contas de anúncios.

</details>
