# Instalar o servidor MCP no ChatGPT Work

Ao receber “instale esse plugin” com o link do projeto no Work ou Dot, execute o cadastro pelo navegador usando Computer Use. Comece mesmo que o plugin ainda não apareça na busca. A instalação termina quando a pessoa pode assumir a vinculação no menu do conector web.

1. **Localize a aba da pessoa.** Use Computer Use para localizar uma aba existente de `https://chatgpt.com` no navegador da pessoa. Prefira a aba que ela indicou e confira se a sessão está autenticada no workspace de destino. Se houver dúvida entre contas ou workspaces, peça que ela indique a aba correta antes de alterar algo. Se não houver aba do ChatGPT aberta ou a sessão estiver desconectada, diga: “Abra uma aba do ChatGPT no seu navegador, entre no workspace em que quer usar o Meta Ads e me avise quando estiver pronto.” Aguarde, localize novamente a aba e retome. Não abra uma janela nova, um navegador isolado ou uma sessão anônima. Se a ferramenta não enxergar a aba que a pessoa já abriu, peça que disponibilize essa aba ao Computer Use. Se a ferramenta estiver indisponível, informe o bloqueio e aguarde.
2. **Procure o conector web existente.** Na mesma aba, abra **Plugins**. Confira **Pessoal**, os plugins instalados e, se necessário, o catálogo do workspace. Abra os detalhes do candidato e confira se é um conector web para `https://mcp.facebook.com/ads`. Uma entrada com **Abrir no aplicativo para desktop** e uma lista de servidores e habilidades é o pacote de desktop. Preserve essa entrada e procure o conector web. Se houver um conector web correspondente, reutilize-o e vá ao passo 4. Se a identidade de uma entrada web for incerta, esclareça antes de criar uma duplicata.
3. **Cadastre somente se estiver ausente.** Na mesma aba, abra **Plugins → + → Adicionar servidor MCP personalizado**. Preencha o nome **Meta Ads MCP – Gestão**, selecione a conexão por HTTPS e informe `https://mcp.facebook.com/ads`. Escolha **OAuth** e, nas opções avançadas, **Registro dinâmico de cliente (DCR)** quando a descoberta oferecer. Se houver campo para ícone, use o [PNG do projeto](https://raw.githubusercontent.com/zaip-ai/zaip-plugin-meta-ads-mcp-gestao/main/assets/meta-ads-icon.png). A descrição sugerida é “Consulte relatórios e gerencie campanhas nas contas autorizadas pela Meta. Alterações somente após confirmação explícita.” Revise a configuração e os avisos apresentados e selecione **Criar como plugin**. Se a resposta demorar ou for ambígua, consulte novamente a lista antes de repetir. Se faltar permissão para criar ou o OAuth exigir dados de cliente indisponíveis, informe a etapa bloqueada. Não substitua o cadastro por upload de ZIP, Plugin Creator ou instalação local.
4. **Abra o menu e pare em Conectar.** Se o conector web ainda oferecer **Instalar**, selecione essa opção. Abra os detalhes ou as configurações do conector instalado. Assim que **Conectar** estiver visível, deixe a aba nessa tela e diga “O conector está pronto neste workspace. Clique em Conectar quando quiser vincular seu Facebook.” Não clique em **Conectar** nem em **Conectar outra conta**. Se a interface já mostrar uma conta conectada, preserve o vínculo e encerre informando o estado observado. Se o ChatGPT abrir o OAuth automaticamente durante a criação ou a instalação, pare na primeira tela de autorização e entregue o controle à pessoa. Se o botão não aparecer, relate o que está visível, sem declarar o cadastro pronto.

A pessoa faz o login, escolhe os ativos e concede acesso na tela oficial da Meta quando quiser. Durante a instalação, não peça credenciais no chat, não liste contas de anúncios e não execute ações de gestão.
